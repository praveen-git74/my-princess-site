# My Princess — Birthday Website

A pastel scrapbook-style birthday surprise for a sister. This public-safe version keeps the hero, heartfelt letter, interactive birthday wish, and closing message. It removes personal photo galleries, memory/timeline boxes, the thought jar, and editing/import controls.

## Run locally

```bash
npm install
npm run dev
```

## Build for deployment

```bash
npm run build
```

## Deploy

Push this project to GitHub, then import the repository at https://vercel.com/ and use the default Vite settings.

**Privacy note:** This is a public static website, not a password-protected private site. Do not add private photos, names, or sensitive memories to a public repository or public deployment.
